# directory-index-generator

扫描一个目录，生成带 **实时搜索 / 排序 / 展开折叠** 功能的静态 HTML 文件索引（脚本：`generate_index_v8_3.py`）。

## 功能

- 📁 递归扫描目录，生成树形结构索引
- 🔍 实时搜索文件名 / 文件夹名（防抖 + 命中高亮）
- 🔃 按 **名称 / 类型 / 修改时间 / 大小** 排序，中文文件名按「数字 → 英文 → 中文」智能排序
- 📂 全部展开 / 全部折叠
- 📊 统计卡片：文件夹数、文件数、总占用空间、生成时间
- 🚫 自动跳过隐藏 / 系统文件夹，支持自定义排除目录
- 🎨 按文件类型显示图标
- 💾 生成后可选备份到其它目录

## 环境要求

- Python 3.x（自带 `tkinter`，无需额外安装第三方库）

## 使用方法

1. 运行脚本：

   ```bash
   python generate_index_v8_3.py
   ```

2. 在弹出的对话框中选择要索引的目录。
3. （可选）输入需要额外排除的子目录，每行一个。
4. 等待生成完成，目录下会生成 `index_<时间戳>.html`。
5. 用浏览器打开该 HTML 即可浏览、搜索、排序。

## 说明

- 生成的 HTML 是纯静态文件，可离线使用，无需服务器。
- 默认排除：隐藏 / 系统文件夹、`$RECYCLE.BIN`、`System Volume Information`、`found.000`。
- 文件链接使用 `file://` 协议，需在本地浏览器打开才有意义。
